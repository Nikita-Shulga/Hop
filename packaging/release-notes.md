One-click Connect to your other computers over the internet:

- Computers you connect to from Hop's connection window now stay under **Your devices** in the Hop window, with a **Connect** button.
- If the connection window remembers the password (it does by default), one click opens the computer and signs in. Remove a computer from the list with **×**.
- Computers you connected to before this update appear the next time the connection window opens.
- Only the computer's ID, name and system are kept in the list; passwords stay in the connection window's own storage, as before.

Windows and macOS use the same host, viewer and protocol code. Windows still requires a virtual display driver or HDMI dummy plug to create an additional host display; Mac hosts can create a virtual display directly. See the [validation checklist](https://github.com/Nikita-Shulga/Hop/blob/main/docs/VALIDATION.md) for automated coverage and checks that require physical devices or separate networks.
